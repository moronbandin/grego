# 4. A formación de adverbios (de modo-cantidade)

#### 4.1. Cualificadores

Os adverbios de modo só modifican o verbo.

##### Regra de formación

- Base: adxectivo cualificador.
- Sufixo: `-ως`.

##### Exemplos

- `ἀγαθός` → `ἀγαθῶς` (`εὖ`)
- `κακός` → `κακῶς`
- `ταχύς` → `τάχεως` (`τάχα`)

#### 4.2. Cuantificadores

Os adverbios de cantidade modifican o verbo e mais os modificadores.

##### Regra de formación

- Base:
- adxectivos cuantificadores indefinidos
- adxectivos cualificadores de medida
- Sufixo: desinencias neutras, singular ou plural.

##### Exemplos

| Adxectivos de medida | Valor | Adxectivos cuantificadores | Valor |
| --- | --- | --- | --- |
| μέγας → μέγα | grandamente (*moito*) | πολύς → πολύ | moito |
| μικρός → μικρόν | pequenamente (*pouco*) | ὀλίγος → ὀλίγον | pouco |
| εὐρύς → εὐρύ | anchamente (*moito*) |  |  |

Os ordinais seguen as mesmas regras de formación e toman un valor temporal:

- `πρῶτος` → `(τὸ) πρῶτον`, `(τὰ) πρῶτα`: *primeiramente*
- `πρότερος` → `πρότερον`: *anteriormente (antes)*
- `ὕστερος` → `ὕστερον`: *posteriormente (despois)*

#### 4.3. Comparación dos adverbios

##### Regra de formación

- Comparativo: é igual ao nominativo singular neutro do correspondente adxectivo comparativo.
- Superlativo: é igual ao nominativo plural neutro do correspondente adxectivo superlativo.

##### Exemplos

- `ἀνδρείως` (*valentemente*) / `ἀνδρειότερον` (*máis valentemente*) / `ἀνδρειότατα` (*moi valentemente*)
- `εὖ` (*ben*) / `ἄμεινον` (*mellor*) / `ἄριστα` (*moi ben*)
- `πολύ` (*moito*) / `πλέον` (*máis*) / `πλεῖστα` (*moitísimo*)

Cuantificadores sen correlación adxectiva:

- `ἦκα` (*pouco*) / `ἧσσον` (*menos*) / `ἥκιστα` (*minimamente*)
- `μάλα` (*moito*) / `μᾶλλον` (*máis*) / `μάλιστα` (*maximamente*)
