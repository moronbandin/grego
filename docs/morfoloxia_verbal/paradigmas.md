# 5.2. Paradigmas básicos de conxugación

As táboas seguintes recollen os paradigmas xerais do verbo regular `λύω` nas tres voces.

##### 5.2.1. Voz activa

###### Presente

| Modo | Formas |
| --- | --- |
| Indicativo | λύω, λύεις, λύει, λύομεν, λύετε, λύουσι(ν) |
| Imperativo | λῦε, λυέτω, λύετε, λυόντων |
| Subxuntivo | λύω, λύῃς, λύῃ, λύωμεν, λύητε, λύωσι(ν) |
| Optativo | λύοιμι, λύοις, λύοι, λύοιμεν, λύοιτε, λύοιεν |
| Infinitivo | λύειν |
| Participio | λύων, λύοντος / λύουσα, λυούσης / λῦον, λύοντος |

###### Imperfecto

| Modo | Formas |
| --- | --- |
| Indicativo | ἔλυον, ἔλυες, ἔλυε(ν), ἐλύομεν, ἐλύετε, ἔλυον |

###### Futuro

| Modo | Formas |
| --- | --- |
| Indicativo | λύσω, λύσεις, λύσει, λύσομεν, λύσετε, λύσουσι(ν) |
| Optativo | λύσοιμι, λύσοις, λύσοι, λύσοιμεν, λύσοιτε, λύσοιεν |
| Infinitivo | λύσειν |
| Participio | λύσων, λύσοντος / λύσουσα, λυσούσης / λῦσον, λύσοντος |

###### Aoristo

| Modo | Formas |
| --- | --- |
| Indicativo | ἔλυσα, ἔλυσας, ἔλυσε(ν), ἐλύσαμεν, ἐλύσατε, ἔλυσαν |
| Imperativo | λῦσον, λυσάτω, λύσατε, λυσάντων |
| Subxuntivo | λύσω, λύσῃς, λύσῃ, λύσωμεν, λύσητε, λύσωσι(ν) |
| Optativo | λύσαιμι, λύσαις, λύσαι, λύσαιμεν, λύσαιτε, λύσαιεν |
| Infinitivo | λῦσαι |
| Participio | λύσας, λύσαντος / λύσασα, λυσάσης / λῦσαν, λύσαντος |

| Participio | λελυκώς, λελυκότος / λελυκυῖα, λελυκυίας / λελυκός, λελυκότος |

| --- | --- |
| Indicativo | ἐλελύκειν, ἐλελύκεις, ἐλελύκει, ἐλελύκειμεν, ἐλελύκειτε, ἐλελύκεισαν |
