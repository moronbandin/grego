# Fenómenos fonéticos  
## Punto de articulación e modo de articulación

## 1. Por que explicamos isto?

Ao estudar procesos como **asimilación, disimilación, aspiración, sonorización** ou **espirantización**,  
é esencial comprender como se producen fisicamente os sons e en que se diferencian.  

Se isto non se entende, a fonética histórica do grego parece arbitraria.

---

## I. Punto de articulación (onde)

O **punto de articulación** é o lugar do tracto vocal onde a lingua, os beizos ou outros órganos  
articulatorios se tocan ou case se tocan para producir un son.  

O punto é o sitio onde o aire atopa un obstáculo.

![Puntos de articulación](https://lh6.googleusercontent.com/proxy/UMqiwW-H69BbSiYbr9586HB_WGLI4v4HN3CEYMLA6H7GYZ3OjTI55Yh7mZxzMmn5KNMOJCqv75eL9fREy0vPaumRrX9mINGxBwvN9WcxPvQl3OdW6ieNNXu7Sna2pFg)

### Exemplos xerais

- **Bilabial**: beizos xuntos → /p, b, m/  
- **Dental**: lingua contra os dentes → /t, d/, θ do inglés *think*  
- **Alveolar**: lingua detrás dos dentes → /s, n, l, r/  
- **Palatal**: lingua cara ao padal duro → /ʝ/, /ɲ/  
- **Velar**: parte posterior da lingua contra o padal brando → /k, g/  

### No grego antigo

- π /p/ → bilabial  
- τ /t/ → dental  
- κ /k/ → velar  

Estas tres consonantes comparten o mesmo **modo** e só cambian no **punto de articulación**.

---

## II. Modo de articulación (como)

O **modo de articulación** describe como sae o aire ou como se bloquea durante a emisión dun son.  

O modo indica como abrimos ou pechamos a “porta do aire”.

### Tipos principais

1. **Oclusivas** → bloqueo total seguido de liberación (p, t, k; b, d, g)  
2. **Fricativas** → fricción sen peche total (f, s, θ)  
3. **Nasais** → aire pola nariz (m, n)  
4. **Laterais** → aire polos lados (l)  
5. **Vibrantes** → lingua vibrante (r, rr)  
6. **Aproximantes** → constrición mínima ([β̞, ð̞, ɣ˕])  

### No grego antigo

- π, τ, κ → oclusivas  
- φ, θ, χ → fricativas aspiradas  
- μ, ν → nasais  
- λ → lateral  
- ρ → vibrante  

---

## III. A diferenza en dúas frases

O **punto** indica **onde** se produce o son.  
O **modo** indica **como** se produce o son.

![Modos de articulación](https://academialatin.com/wp-content/uploads/inventario-fonemico-consonantes-espanol.png)

- π e φ teñen o mesmo punto (bilabial) pero distinto modo.  
- π, τ, κ teñen o mesmo modo (oclusivas) pero distinto punto.

## IV. Aplicación práctica: asimilación, disimilación e outros procesos

### 1. Asimilación

É cando un son adopta un trazo doutro próximo.  
Especialmente común: **nasal + oclusiva**.

- γγ, γκ, γξ, γχ → nasal velar [ŋ]  
- ἐμ-βαίνω → [embaino]  
- ἐν-τείνω → [enteino]  

**En latín e romances:**

- in- + p/b/m → im-  
- in- + l/r → il-, ir-  
- in- + k/g → [iŋ-] na pronuncia  

---

### 2. Disimilación

Proceso menos frecuente: dous sons similares afástanse.

- *medio-diēs* → *merīdiēs*  
- *venēnum* → *veleno*  
- *hóminem* → *hombre*  

**Lei de Grassmann:**

- θί-θη-μι → τί-θη-μι  
- *bʰeh₂ǵʰús-* → πῆχυς  
- ἕχω → ἔχω  

---

### 3. Sonorización e aspiración

- π → β  
- τ → δ  
- κ → γ  

**En romances (sonorización intervocálica):**

- *lupum* → *lobo*  
- *rotam* → *roda*  
- *delicatus* → *delgado*
